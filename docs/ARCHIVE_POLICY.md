# Archival scope, selection and integrity policy

Snapshot date: 2026-10-29. All existing scientific trees were recursively inventoried before writing documentation. [FILE_INVENTORY.csv](manifests/FILE_INVENTORY.csv) retains exact sizes, original mtimes, available SHA-256 and per-file disposition. Protected `.git`, `.agents`, `.codex` and `.aws` directories were empty at initial inspection and were not treated as scientific inputs. Installed `.venv` contents are inventoried but excluded from publication.

Selection is **file-level**, never a blanket exclusion of scientific analysis directories. Include original project source, every notebook, Markdown/HTML reports, CSV and compressed CSV tables, PNG/PDF figures, JSON configurations/results, joblib fitted models and small logs/receipts. Include diagnostic NPZ arrays up to2MB unless they are explicitly input/extracted/observation caches. All selected originals are below25MB; the conservative limit is an archive choice, not a claim about GitHub's current maximum size. None of the13 notebooks required stripping outputs (largest below8.1MB).

Exclude raw FITS/FITS.gz and downloaded tar archives; bulk NPZ/caches; installed environments/bytecode/transient PID/lock files; unclassified payloads; third-party downloaded calculator/forward/template assets without established redistribution terms. Preserve everything in place. The manifests document **every** excluded scientific output, exact server preservation path and reason; no file is deleted, altered or compressed to fit publication.

Source manifests and existing frozen hashes preserve third-party provenance. Public retrieval does not establish redistribution permission. No license is invented over external code/data. The absence of a published payload does not mean its scientific outcome was discarded. Large arrays have table/report/inspection-figure counterparts where existing artifacts provide them; remaining clone-only reproduction limits are explicit.

The existing source and results remain byte-for-byte intact. Before/after verification hashes every selected original file and compares all baseline paths/sizes/mtime_ns. Original raw FITS/archives/bulk arrays are checked by original size/mtime plus their historical hashes/integrity receipts; this task does not claim to have freshly rehashed every84GiB. Preservation of excluded bytes still depends on server backup/retention.

Git staging uses an explicit NUL-delimited allowlist generated from screened originals plus newly authored archive files. `.gitignore` contains exact withheld paths and secret/runtime exclusions; `.gitattributes` disables newline conversion to preserve frozen bytes. No `git add .`, force-push, rewriting of unrelated commits or invented historical commits is allowed. A later sync receipt references the archive parent SHA, because a document cannot contain its own final commit SHA.

Publication screening checks literal credential patterns, private-key markers, credential-like assignments and signed access URLs across text/notebook/JSON/log/XML content. Findings that are variable references or synthetic fixtures are manually distinguished. This is a documented content screen, not a proof that arbitrary unknown secrets can never exist. No user credential file was opened for this archive.

Fresh **archive-only** checks are separate from saved scientific validation. No scientific test scripts, notebook execution, model loading/training/inference, source-label audit, forward modeling, DR2 investigation or HAWK-I reduction is part of archival verification. [Sync report](GITHUB_SYNC_REPORT.md) records counts, hashes, remote verification and any blocker honestly.

The security screen found the downloader test's deliberately synthetic query URL containing `synthetic-test-key`. This exact fixture was manually confirmed to be non-secret and is the only explicit content exception; credential-bearing URLs remain screened. Four inherited links in a copied historical JWST-method README point to files absent from the original local project. They are recorded in [HISTORICAL_LINK_GAPS.json](manifests/HISTORICAL_LINK_GAPS.json); archival documents/figure/table indexes introduce no broken links, and original historical prose is preserved.
