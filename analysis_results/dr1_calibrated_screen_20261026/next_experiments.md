# Prioritized next experiments

1. **Repair the observational population model before seeking a positive dust claim.** Use positive mixtures of independent training-region SEDs, a shared physical morphology, and multiplicative population/attenuation fields projected through each band's PSF. Current additive Gaussian colour fields fail native z=.3 posterior predictions. Freeze complexity using training-only spatial validation; do not choose priors to pass a particular null. Preserve age-dependent birth-cloud uncertainty separately from an additional diffuse foreground screen. A physical SFH/metallicity interpretation requires a verified clean SPS grid; the present empirical PCs are not such a grid.
2. **Require both predictive adequacy and calibrated error control.** Test the existing fixed population anchors as well as independent random fields and attenuation profiles. Reuse new noise seeds and a new untouched evaluation split after any model change. Report performance at declared null distributions and worst tested settings; ensemble-average FPR does not guarantee pointwise control. Keep exact Poisson/read and normalization checks. Include higher population residual modes, spatial correlation-length sensitivity and parameter coverage; the current generator samples only two PCs.
3. **Repeat the GLAO comparison with a valid native-resolution model.** Same source, per-band exposure budget, noise pairing and error criterion. Keep the optical PSFs seeing-limited. Compare native forward modelling with common-PSF colours; failure to exploit a narrower PSF is a model limitation, not physical information loss. Validate actual PSFs and reduction noise; HAWK-I compact-source fits remain provisional. Include empirical sky/flat-field residuals after proper HAWK-I calibration, not raw frames treated as calibrated mosaics.
4. **Make any real ULTIMATE forecast in supported observer filters.** Current tests preserve DR1 rest bands and use provisional nominal-band electron proxies. Rest Ks atz=.3 is outside ordinary Ks; do not present the seven-band result as realizable observer photometry. Use resolved spectral information or validated limited filter mapping and actual throughputs/thermal backgrounds before estimating observable survey gains. Keep intrinsic evolution separate from static transfer.
5. **Validate by galaxy.** Only294866 is available locally. Its five orientations are correlated sensitivity cases. Keep future locally supplied galaxies separate by galaxy for development and final evaluation. No automatic downloads are planned.
6. **Defer ML.** Consider learning a dust-sensitive statistic only after independent physical nulls, population anchors, noise/systematic models and observer passbands are validated. A reliable negative workshop result is already available; no large training run is justified by the present results.
