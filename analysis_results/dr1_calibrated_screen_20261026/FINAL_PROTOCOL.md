# Final robust conditional calibration protocol
Frozen after development stress tests demonstrated failure; the stress-test evaluation set is now DEVELOPMENT evidence, not final evidence. Priors and original statistic are unchanged. No final ensemble draws were inspected when writing this protocol.

Use PC2 + measured residual population covariance, intrinsic RBF normalization fixed across strategies, and 2*log marginal likelihood ratio as in experiment.py. Fit observed linear flux contrasts with observed normalization Jacobians.

For generator population uncertainty, create six bounded physical-coordinate fields (three smooth modes and three patch fields), unrelated to SKIRT dust. Multiply the *same* clear DR1 scene by `1 + sum_j sqrt(eigenvalue_j)*PC_j*field_j` for j=1,2. Each field is a convex combination of bounded modes with signed coefficients whose L1 norm <=1; thus every band remains positive and colour excursions are bounded by the independently measured training scatter. These empirical SED shifts are not assigned physical SFH/age/metallicity values. This is a declared population-stress ensemble, not an astrophysical galaxy distribution.

For each observing condition and each of five global uniform-screen nulls (E=0, E=.15 n=1, E=.35 n=.7/1/1.3), use 500 population+noise realizations for calibration. The cutoff is the maximum of their finite-sample 95% order statistics. Use 500 NEW population+noise realizations per null and per smooth/patchy alternative for final evaluation. Also use 500 new noise draws on unchanged original SKIRT. Calibration and evaluation RNG streams are separate; common random numbers pair seeing/GLAO and screen controls.

The same population perturbation precedes attenuation and PSF in matched null/variable pairs. No galaxy intrinsic evolution across redshift. Population realizations differ *across robustness trials*, not as a function of redshift. Fields are fixed in kpc. Optical-only, NIR-only and joint results are prespecified. Primary conditions: O1 z=.1/.3, seeing/GLAO, matched/native, 1h per band. Other views remain development/sensitivity tests, not independent validation galaxies.

Report exact binomial intervals, conservative paired-discordance intervals and multiplicity-adjusted McNemar tests. Posterior prediction on the first held-out realization is a diagnostic; no result is promoted to a physical geometry detection when the model is inadequate. Fixed calibration-cutoff intervals do not include uncertainty in the stellar-population ensemble itself. No generalization claim beyond this galaxy and bounded empirical ensemble.
