# Final review and limitations

A separate read-only reviewer examined the protocol, measurement, archive, observing, statistics and validation modules, report and saved tables. It independently reconstructed galaxy scores (agreement within 2.22e-16), eight Ks gains/seeded bootstrap intervals and native g/Ks median R50 contrasts. It found no consequential numerical flaw within this bounded scope. It identified one presentation ambiguity: the main observing table did not explicitly name its band. The renderer now labels it **2MASS Ks only**; g is an identical-strategy control and J results remain in the full tables. This is a bounded computational review, not astrophysical source-model validation or certification of final instrument assumptions.

The author also found and corrected a legacy import-path collision. It had re-rendered nine prior pilot PDFs, changing only their creation timestamps. Each was restored to its exact original SHA256 by restoring that metadata, with a receipt in legacy_PDF_restoration.json. All 289 checked prior result files match the original manifest. A regression test now verifies that importing the read-only legacy forward model cannot select the old renderer.

Integrity nuance: tarfile's streaming raw-gzip decoder alone is not an independent gzip CRC validator. The 25 extra archives have current hashes and byte lengths identical to their downloader-verified files, preserving that recorded gzip CRC proof. The original archive was independently drained with gzip.GzipFile, validating its trailer. CRC_evidence distinguishes these cases. Cache-free reproduction now uses gzip.GzipFile around tar streaming, checking CRC directly during the necessary data pass. A corrupted-trailer regression test fails as expected.

Scientific limitations are retained: four zero-projected-dust objects have nonzero pair residuals; source/filter integration, projection, radiative-transfer noise and unresolved components cannot be separated with these inputs. No empirical offset was subtracted. All 26 galaxies remain in the native study. Thirteen noisy Ks q rows are missing; joint-valid pairing and the pre-evaluation 6/8 rule avoid unequal strategy samples. All 26 remain eligible for the reported primary targets, but sensitivity cases can have fewer valid objects. R12 aperture limitations affect 15 galaxies. Five views are correlated and include antipodal O4/O5; a four-view sensitivity is supplied. The held-out subset omits four low-mass development cells and is therefore not balanced like the initial 25-object draw. The conditional bootstrap does not turn either subset into a representative population estimate.

The most defensible instrumental result is improved Ks R50/concentration preservation under the specified Gaussian proxy scenario. Dust-difference gains are smaller, metric dependent and subject to the unresolved source residuals. Asymmetry preservation changes sign with the noise estimator. No universal ULTIMATE or unique-dust-feature claim is supported. Existing atlas morphology studies overlap the physical question; paper novelty must come from calibrated instrument transfer and validation.
