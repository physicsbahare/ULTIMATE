# Frozen pilot protocol — 2026-10-26

Question: detect observable structure and quantify dust-induced morphology changes, not infer 3D geometry. One galaxy, five correlated orientations. Previous negative inference findings remain valid.

Use actual DR1 g, 2MASS J and Ks, 100 pc source pixels, central 40 kpc, padded before convolution; measurement radius 12 kpc in a 32 kpc output field. Illustrative matched-rest-band degradation at z=0.05 and 0.1 with I_nu/(1+z)^3. No K-correction or source evolution. Detector pixel 0.1 arcsec; existing provisional electron conversion, sky, thermal, dark and read noise. 60-second reads; depth is per band, total budget three times depth. g stays seeing limited. Gaussian baseline; equal-D50 Moffat sensitivity only for native Ks/morphology, without assuming Gaussian PSF matching for Moffat.

Main O1: both distances, 0.25/1/4 hours per band, seeing/GLAO. O2–O5: z=0.1, one hour, seeing/GLAO. Forty independent final noise draws per condition/scene, paired standard normal innovations across modes and scenes. Independent seeds for 40-draw delta-method/covariance calibration (not used to select thresholds). Gaussian detector noise has exact split-exposure moments; compare separate exact aggregate Poisson + read draws. No expensive Bayesian grids.

Scenes: dust-free DR1, spatially constant E(B−V)=0.15 screen, stellar-only smooth/patchy colour shifts (independent fixed seed), and original SKIRT. Uniform screen follows previous k(lambda) proportional lambda^-1 normalized by k(B)-k(V)=1. Image-level coefficients at approximate pivots are broadband approximations. No screen is fitted. Stellar-only shifts change positive stellar fluxes, no dust. These stress controls are deliberately not a claimed full population distribution.

Measurement API accepts observed band images, variance, pixel scale and supplied PSFs only. It never receives clear counterparts or dust maps. For Gaussian baseline: g−Ks matched to 0.8 arcsec; J−Ks matched within NIR to max(J,Ks) PSF of its own observing mode; Ks native unsharp deficit. FWHM analysis smoothing scales 0.5,1,2 kpc; broad kernel three times each scale. Effective smoothing scale is not a measured object diameter or proof of simulation resolution. Colour structure is fine-minus-broad colour; brightness deficit is 1−fine/broad intensity.

Fixed criteria, before evaluation: positive feature exceeds both 3 local propagated noise standard deviations and 0.05 mag (colour) / 0.03 (Ks fractional deficit); fine and broad flux S/N>10 in relevant bands. No thresholds chosen using evaluation truth. Spatial covariance of smoothing/matching retained via combined linear kernels, including fine/broad cross covariance, then a first-order ratio/log Jacobian. No independent-pixel significance or error bars. 180-degree asymmetry subtracts expected absolute Gaussian noise; concentration and R50 use signed sky-subtracted flux within fixed R<12kpc and fixed central coordinate, no positive pixel clipping. These are defined pilot statistics, not a complete survey morphology pipeline.

Truth is used only in rendering and scoring: A_eff=−2.5log10(dusty/clear), retain negative attenuation; positive intensities and clear>1e−4 band peak, R<12kpc. Intrinsic reference structures are measurement(SKIRT)−measurement(clear), on the same detector grid with source-pixel area integration but no observational PSF, at each analysis smoothing scale. Positive references above same amplitude cuts. Unobservable reference pixels count as missed. Report native reference overlap, PSF-limited overlap, Pearson/rank associations, pixel-area completeness/contamination and component overlap (30% area); never call every positive feature dust. Per-control candidate area and false candidate incidence quantify ambiguity without truth attribution. Noise intervals describe repeated observations of this one fixed scene, not independent galaxies. Surface brightness strata and orientation axis ratios are diagnostics, not exact inclinations.

Decision: if false dust attribution is high in stellar-only controls, presentation pivots to paired dust-induced morphology bias and measured spatial-transfer effects. GLAO benefit stays conditional on PSFs/noise/bands, and differences must be paired across the same noise draws. No universal size limit or dust mass/geometry claim.
