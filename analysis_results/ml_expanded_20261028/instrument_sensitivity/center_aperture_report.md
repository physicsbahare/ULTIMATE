# Executed native-label center and aperture robustness

This diagnostic uses precisely the existing sensitivity subset: first six frozen development IDs (controls included) and all fourteen validation IDs, O1 only. It measures all eight frozen `labels_for` targets on the native 0.1-kpc images. It does not alter root code, models, partitions, target definitions, or measurement choices, and opens no final-test science. The baseline radius is recomputed once with the frozen dusty-Ks common-seeing policy and then held fixed during center perturbations.

Seven cases are evaluated for each galaxy: baseline, 0.8 times the baseline radius, 1.2 times the radius capped at 35 kpc, and aperture-center shifts of +0.5/-0.5 kpc along each of x and y separately. Each shifted case applies the same operator to clear and dusty images. To move the aperture center toward positive original x/y, both images are translated by the opposite displacement before the unchanged fixed-center label function is called. These shifts are exactly five native pixels. The prescribed order-1 constant-zero interpolation therefore samples integer native pixels without interpolation mixing or a band-axis displacement.

`center_aperture_target_changes.csv` contains one row per galaxy/case/target: partition, radius, center offsets, native pixel size, value, frozen baseline value, signed difference, absolute difference, and radius-cap flag. It has 1,120 rows. `center_aperture_targets_wide.csv` provides all eight target values on 140 galaxy/case rows. `center_aperture_summary.csv` reports galaxy-level median/mean differences, median/90th-percentile/maximum absolute differences, and strict sign-flip counts, separately for all20, development6 and validation14. These are descriptive selected-sample sensitivities, not population uncertainty estimates; no bootstrap intervals or claim of independent calibration is attached. Near-zero source controls remain in the outputs and can make a strict sign change scientifically uninformative.

The independent numerical checks compare six analytic flux/morphology targets against direct off-center `Geometry` measurements on the unshifted input arrays. They also compare clear and dusty aperture fluxes before/after coordinate translation. Every target is checked finite; baseline values are compared against independently saved nonfinal root labels wherever present. `center_aperture_numerical_checks.csv` records per-case results, and `center_aperture_verification.json` gives executed maxima and counts. The maximum test aperture plus center displacement plus the full five-sigma support of the one-kpc attenuation smoothing remains inside the native 40-kpc half-field, so zero-fill boundaries cannot enter a measured aperture through that smoothing operation.

Executed checks pass for all 20 galaxies: all 1,120 values are finite; all 20 saved root baselines match within 2.22e-16; direct-geometry target checks differ by at most 1.78e-15; clear/dusty aperture-flux relative differences are zero. Minimum field-edge margin after smoothing support is 7.24 kpc. No radius cap is triggered in this subset. The selected radii therefore test exactly the requested 0.8/1.2 scalings.

The fourteen validation galaxies show the following median absolute changes; center columns give the range across the four separately applied directions, rather than an uncertainty interval:

Thus native integrated attenuation is much less affected by the tested center shifts than by changing the enclosed aperture. Concentration differences can be materially center dependent: the largest validation absolute dC_Ks change is 0.44709 for the +y case. Radius ×0.8 changes validation A_g_p50_1kpc by up to 0.13139 mag and dR50_Ks by up to 0.12489 kpc. These operator sensitivities should be retained beside the predictive-error results; they do not by themselves establish corrected labels or model-performance changes. Full eight-target signed distributions and strict sign-flip counts remain in the CSVs.

Attenuation targets and concentration differences use magnitude units; R50 differences use kpc; the attenuation IQR is in magnitudes. Changing radius changes both enclosed clear/dusty light and the valid attenuation-pixel population. The attenuation validity threshold retains the original rule relative to the full smoothed clear-image peak. These are noiseless native source-label sensitivities; no observed PSF/noise features or predictions are recomputed. A fixed half-kpc center perturbation is not an estimated centering error distribution. Only O1 and separate one-axis center/radius perturbations are tested, without combined center/radius changes or arbitrary rotations. Large changes identify conditional operator dependence, not errors in the original source products or a calibrated total systematic error bar.

Read-only geometry/noise feature review found no implementation defect. The 800-pixel source image padded by 80 pixels matches the 961 native edges; output crop and `FeaturePlan` coordinates use consistent centered even grids and kpc-per-arcsec conversion. Native variance is in squared rate units for 3,600 seconds and 60 independent 60-second reads, consistent with the rendered rate images. Mode innovations are paired and the adaptive radius is shared. Noise-sensitive asymmetry and texture remain observable inputs without per-image noise subtraction; their sampling dependence is visible in the separate software-binning diagnostic. Source amplitudes/passbands, independent native detector noise, known sky/registration, and provisional PSFs remain inherited conditional assumptions.
