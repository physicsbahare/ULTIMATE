# Conditional instrument sensitivity and HAWK-I sharing manifest

This O1-only sensitivity uses the first six development galaxies in the frozen partition file (including the zero-dust controls) and all fourteen validation galaxies. The choice uses file order, without labels, qualitative image selection, training, or retuning. No final-test science is opened. The frozen common seeing dusty-Ks adaptive aperture and the existing `FeaturePlan` define every measurement.

The separately requested native-label operator test is documented in [center_aperture_report.md](center_aperture_report.md), with 0.8/1.2 aperture scalings and ±0.5-kpc center shifts. That follow-up reads the same twenty nonfinal paired clear/dusty O1 images and saved labels; it does not change this instrument-feature run or train any model.

| Case | Modification |
|---|---|
| A | Gaussian baseline, inherited one-hour per-band rates and native independent-pixel variance |
| B | Ks-only circular Moffat wings, beta=3.7414837; retain mode-specific provisional D50 |
| C | B with Ks separable nearest-neighbor correlation, target rho_x=0.2752555 and rho_y=0.29317406; innovations normalized to unit variance |
| D | Software 2x2 sums of the exact A noisy image and its native variance; 0.2-arcsec samples over the identical physical footprint |

Both modes and all four cases share four native Gaussian innovations per galaxy. There are 640 rows when complete. The output `stress_features.csv.gz` has metadata `subhalo_id,view,draw,partition,aperture,condition,mode,case`, then exactly the existing observable `FeaturePlan` columns. `aperture=adaptive`, `condition=nominal`, `view=O1`. Use the frozen fitted models for validation scoring; these files contain no model selection or new model fit.

The provisional D50 values are g=0.700 arcsec in both modes; J=0.65783/0.50766 and Ks=0.58814/0.38955 arcsec for seeing/GLAO. The HAWK-I measured FWHM is not substituted for an ULTIMATE PSF width. The Moffat kernel converts D50 to alpha using the analytic enclosed-light relation, samples through 12 alpha, and normalizes its finite kernel to sum one. The global renderer kernel is restored with `finally` after every modified rendering.

The nine quality-matched stellar sources have beta median 3.74148 (IQR 3.43351–3.95007), whereas the 103 isolated compact-source candidates have median 4.75296. The latter are not all catalog-confirmed stars. The small, selected nine-star subset and its difference from the full sample remain uncertainty; the present test is a conditional wing sensitivity, not a universal empirical PSF calibration. Circular, spatially invariant kernels omit measured ellipticity, spatial variation, PSF-estimation errors, and registration errors.

Case C filters the Ks total standardized innovation and then scales it by the provisional pixel variance. It does not transfer raw ADU amplitudes or infer a source/sky covariance decomposition. The separable three-tap filter has no covariance beyond two pixels along either axis. It omits long-range background structure and the real reduced mosaic's excess large-aperture sky noise. Periodic filter boundaries lie outside the measurement aperture. This is explicitly not a full sky model.

Case D sums all four native source, sky, dark, and read contributions to each new pixel variance under the baseline's known independent native covariance assumption. No coarse-pixel detector variance calculation is used: there is no fictional detector redesign or reduction in the number of reads. Detector-coordinate centers are recomputed at 0.2 arcsec with the exact original footprint. Summed fluxes and variances are checked against native totals in `render_validation.csv`; software binning does not recover frequencies removed by a PSF.

`assumptions.json` records exact settings, input hashes, kernel coefficients, simulated noise moments, and scope. `apertures.csv` records all frozen radii. `selected_galaxies.csv` fixes the selection; `status.json` records completeness. `run_stress.py` is the executable source; it writes only this directory and accesses cached dusty O1 images, not labels or clear counterparts. Execute with `PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 /home/bahareh/miniforge3/envs/phd/bin/python run_stress.py`.

The six-row `hawki_sharing_manifest.csv` lists the existing Jan6 science, variance, and confidence/relative-weight cutouts, the associated PHOTCAL_TAB, reduced source catalogue, and 2MASS reference catalogue. Byte counts and SHA256 are recomputed from exact original absolute paths. The confidence map is an ancillary weight/confidence product, not independently calibrated inverse variance. This is a manifest only: no packaging, copying, upload, or transfer occurred, and no new ESO science or calibration image was downloaded or reduced. The image products are target-centered SODA cutouts, not full tiles.

Executed verification passes: 640 rows, 20 galaxies, 180 observable features, and zero nonfinite feature cells. All six available independent development baseline files match A exactly, with maximum absolute difference zero. Maximum padded rendering flux loss is 5.07e-9. Maximum 2x2 total-flux and total-variance relative errors are both 4.44e-16. The one-million-pixel Ks filter check gives variance 1.000620, rho_x=0.276081 and rho_y=0.293047, each within 0.01 of its target. Every manifest SHA and byte count passes a fresh read.

`observable_feature_shifts.csv` reports descriptive paired differences from A, pooling the 20 selected galaxies and four draws (80 values per mode/case). These are not independent population samples or predictive-performance claims. For example, B changes median seeing Ks R50 by +0.02027 kpc, with 90th percentile absolute change 0.08174 kpc; GLAO median is zero on the discrete radius grid. Software binning changes the noise-sensitive Ks asymmetry by median -0.07626/-0.07573 in seeing/GLAO and Ks 0.5-kpc texture by -0.06971/-0.07780. Total image flux conservation does not imply invariant pixel-aperture boundaries or morphology features. Frozen validation-model scoring is separate from these feature-level checks.
