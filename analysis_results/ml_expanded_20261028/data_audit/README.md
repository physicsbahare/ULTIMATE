# Expanded DR1 input audit

`frozen_galaxy_partitions.csv` is copied byte-for-byte from the frozen 86 development / 14 validation / 20 final-test manifest. The final 20 remain sealed: only their compressed archive byte length and SHA256 are read. Previously passed downloader gzip CRC/tar validation is inherited only when current SHA256 and byte length match exactly.

For the 100 nonfinal galaxies, the archives are streamed without extraction. Every regular member is hashed; each analytic FITS header is inspected for dimensions, units and exact common spatial grid. The member basename supplies band identity because these headers have no filter keyword. All 22 dusty/clear band pairs in all five views must exist exactly once, alongside the four physical maps per view (240 members per galaxy). Full pixel arrays are checked for finite/nonnegative values for g/J/Ks dusty+clear and dustmass only. Dust maps allow the pre-existing physical-roundoff tolerance `1e-10 * max(maximum,1)`; the actual minimum/negative fraction are reported. Other arrays have header/hash validation only.

`cache/<subhalo_id>/O1.npz` through `O5.npz` contain seven native float32 arrays: `dusty_LSST_g`, `clear_LSST_g`, `dusty_2MASS_J`, `clear_2MASS_J`, `dusty_2MASS_Ks`, `clear_2MASS_Ks`, `dust`. Each is the native 800×800 central `[400:1200,400:1200]` crop of the 1600×1600 source at 100 pc per pixel; the origin lies between pixels at coordinate 399.5 (zero-based). Native flux units are MJy/sr; dust units are Msun/pc2. `complete.json` is written last, after all five views and archive/header checks pass. Per-galaxy physical.csv records full-field projected dust mass from the uncropped map as sum×10000 pc² and exact-zero projected-dust status, separately per view.

The initial gate uses original 294866 and three new frozen development galaxies (571633, 578834, 319734), with g/J/Ks native R12 morphology checked against the prior original-galaxy primary pairs. `development_gate.json` is written only after all four caches and that comparison pass. No morphology is measured for other bands.

`archive_inventory.csv`, `fits_inventory.csv`, `available_galaxies.csv` and `physical_maps.csv` are rebuilt after completed galaxies; during execution they may lag a newly published per-galaxy `complete.json`. `preparation.log` records progress. Failure records are explicit in `failures.json` after the batch finishes. Downloader logs/state/selection manifests are snapshots in this directory. The script is resumable and skips a completed galaxy's science stream.
