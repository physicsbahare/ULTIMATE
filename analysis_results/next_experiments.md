## 3. Implement the forward operator with explicit units
1. Select physical/angular scale. For local Euclidean D_A, a native 100-pc pixel subtends θ = 206265×100/D_A(pc) arcsec. For example, the **assumed** D_A=100 Mpc gives 0.206265 arcsec per native pixel. A 0.2-arcsec PSF is then smaller than one input pixel: a 0.1-arcsec output grid would interpolate unresolved structure and cannot support a resolved prediction at that PSF. This grid reaches two input samples per 0.2-arcsec FWHM only at D_A ≥206.265 Mpc; underlying source smoothing imposes a further physical limit. Evaluate scale adequacy before running mocks. At nearby NGC 3256-like distances, this atlas cannot validate tens-of-pc dust features; use coarser common physical resolution or obtain justified higher-resolution models in a later approved step.
2. Conserve flux while remapping surface brightness and pixel solid angle. At negligible redshift, surface brightness in MJy/sr is distance independent; integrated Jy follows intensity × pixel solid angle ×10^6. At non-negligible redshift, use specific-intensity transformation Iν,obs(νobs)=Iν,em((1+z)νobs)/(1+z)^3 plus the appropriately shifted bandpass; bolometric dimming is (1+z)^−4. Avoid applying bolometric dimming to a fixed-band MJy/sr image without its SED/K correction.
3. Convolve **intensity** images with unit-integral PSFs before detector-pixel integration and resampling. Never convolve an attenuation map as a substitute for recomputing the ratio. If input and desired PSFs are both known Gaussians, the additional width satisfies σ_kernel²=σ_target²−σ_input²≥0; a negative value means the requested sharpening is impossible by convolution. Atlas 100-pc pixels are not a known Gaussian σ_input. Include pixel response and padding; measure lost boundary flux and verify centroid/flux preservation. Give evaluation truth the same effective spatial resolution.
4. Integrate over detector pixels, use subpixel dither realizations when supported, and carry coverage/weights. Colours require a common effective PSF or a joint forward model with different per-band PSFs. Do not degrade the optical band to a sharper NIR PSF. Both finite input resolution and broader optical seeing can limit the accessible dust signal.
5. Convert flux to expected photoelectrons using an actual photon-counting throughput integral, collecting area, exposure and pixel solid angle. For flux density Fν, the rate uses A∫Fν(ν) T(ν)/(hν)dν, with consistent units. Add Poisson source+sky+dark electrons separately per exposure, Gaussian read noise per readout and calibrated systematic floors; reduce/stack with the same estimator as observations. For summed independent exposures with per-frame signal S, sky B, dark D and read variance RN², the variance is N(S+B+D+RN²), before resampling/background-estimation correlations. Co-averaged data require the corresponding mean normalization. Carry the uncertainty of sky estimation, flat fields and covariance in resampled pixels. Do not invent a conversion between an SNR scenario and hours on sky.
6. Make masks from noisy observable detection/SNR and coverage, with a fixed selection rule, never from dust-free truth or projected dust. Retain nondetections as censored/missing where appropriate; avoid logarithms of nonpositive noisy flux and their selection bias. Use independent noise draws for repeated tests; seed and record them. Noisy-pixel attenuation using the ideal twin is an evaluation diagnostic, not an observable.

## 4. Decide whether information is recoverable
Start with noiseless, flux-conserving PSF/sampling degradation, then add a small noise ladder anchored by a verified budget. If no budget is available, stop at clearly labelled SNR scenarios and state that realistic exposure forecasts remain blocked.

Compare projected dust recovery from g−Ks plus morphology to radius-only, Ks surface-brightness-only, and colour-only baselines. Also compare the ideal-twin attenuation diagnostic to the observable-only case: the gap quantifies how much the current pilot depends on privileged information. Examine radial residuals and subregions with similar stellar brightness; vary masks, PSF wings and sky residuals. Measure rank correlation, log-surface-density error with an explicit detection floor, attenuation bias, spatial contrast and recovered physical scale; show completeness and failures, not only bright detected pixels. Do not use ideal ρ as a prediction accuracy metric for the noisy observable problem.

Use spatial block holdouts larger than the PSF/correlation scale for within-galaxy diagnostics, but call them within-galaxy checks. Rotate through views as a robustness stress test, not an independent-galaxy test. A small linear/ridge or tabulated colour baseline is enough initially. No large neural network is justified by one galaxy. Any uncertainty band must state whether it is noise-realization scatter, parameter-scenario spread, spatial sampling variation or independent-galaxy uncertainty.

**Go/no-go:** advance only when observable-only features add stable information beyond simple baselines at adequately resolved scales and documented noise levels across the tested views. Predefine a scientifically useful accuracy/scale criterion with the supervisor before optimizing. If the signal survives only in the dust-free-twin comparison or at unrealistic depths, report that limit and redesign the experiment.

## 6. Only then expand the sample and define geometry
A modest set of additional independent galaxies spanning inclination, stellar population and morphology is necessary before a generalization claim. Request approval before any large download. Split train/validation/test by galaxy: all views and spatial patches of one galaxy remain in the same split. Distinguish DR1/DR2 models and filters if future data are added.

A 3D target needs explicit simulation labels beyond surface-density maps: e.g. dust vertical thickness, star–dust separation, clumping, or fraction of stars behind dust, with degeneracy tests. Recovering projected mass from colours is a different inference problem. Design controlled radiative-transfer models that vary geometry at comparable projected column and stellar population to test identifiability before attaching a geometry label to machine-learning output.
