# M4-offset empirical calibration protocol

Use the two uploaded science products read-only and the existing phd environment. Write only within this isolated results directory; no ML training, tuning or final-test access. Preserve failed selections and all measured signed backgrounds.

Integrity: SHA256, FITS CHECKSUM/DATASUM, complete HDU/header inventory, exact equality of28 raw PROV IDs, WCS round trips and ancillary crop-grid alignment. Distinguish metadata PSF_FWHM/PHOTZP/QC claims from measurements. Original detector order comes from EXTNAME (1,2,4,3). Both products are resampled stacks; neither is raw or an independent observing realization.

Star detection: spatial1024-pixel cores with64-pixel halos; SEP mesh128 pixels,5sigma detections, minimum6 pixels. Nearest detected source distance>=2.5arcsec; broad shape cuts, no narrow FWHM/roundness locus. Select at most6 candidates per cell, S/N peak>=60. Broad first pass has peak<10000ADU above sky; preserve it as a sensitivity. The conservative primary fainter pass requires peak<5000 and product raw peak<22000ADU. These are product-selection criteria, not a proof of every input raw pixel's linear history. The global QC flag must not be suppressed.

Fit an elliptical3×3-subpixel-integrated Moffat plus plane on41×41pixels, retain failed fits, q>0.4,0.15<FWHM<0.75arcsec,1.2<beta<14.8 and relative residual RMS<0.04. Formal independent-pixel fit errors are not calibrated under correlated noise and are not used as confidence intervals. Use spatial-cell cluster bootstrap for field medians and fit-window13-versus20pixel sensitivity. Conservative core-flatness checks and a brighter/fainter selection comparison assess saturation/model sensitivity.

External identities: GaiaDR3 reference positions propagated2016→2019.635 using proper motions. Query is limited to25000 brightest sources (G<20); absence of a match is not a nonstellar classification. Estimate and report each plane's absolute offset; a registered residual<0.35arcsec and second Gaia source>0.7arcsec define positional validation. ESO catalogue stellar classification with zero bad-pixel count is a separate image-based consistency check, not independent astrophysical truth. Preserve full acceptance/reference flags. Shifted-position association tests estimate chance coincidence. Use unique Gaia IDs for paired-star uncertainty; common photons and spatial covariance prevent treating products as independent experiments.

Empirical EE: signed circular aperture sums at0.1–2arcsec, annular median sky at1.8–2.5arcsec, five-subpixel apertures; normalize separately to finite R1.5 and R2. First cumulative crossing defines R50/R80 even if outer signed growth is not monotonic. No infinite-flux claim. Restrict wing templates to nearest detected neighbour>=4.5arcsec and annular residual sigma<1.5local sky sigma. Moffat infinite elliptical R50 and extended positive kernels are explicit model extrapolations. Compare NGC3256 through this same estimator in a new output table, leaving the earlier calibration untouched.

Noise: nine768pixel spatial grid patches per plane, plus four ancillary variance/confidence sky regions (the pawprint has four extension cutouts in each region). Three-sigma source masks grown by8/12/20pixels, invalid/constant-fill/outlier masks and35pixel edges. Confidence is a relative weight, not inverse variance; variance is squared-image units operationally despite ADU header inheritance. Compare mesh128/256 in the centre and additional faint ESO catalogue masks in the tile. Report pixel MAD/std, axial/diagonal masked correlations and circular R2/4/8/16/32pixel aperture MAD/std. Sample positions may overlap; retain a geometrically disjoint packing count, which is not a proof of independence under long-scale sky correlations. Sparse large-aperture void samples are not accepted as precise noise estimates.

Model family: joint empirical PSF parameter samples and finite positive Moffat kernels; local unit-variance3×3 covariance kernels; separate PSD mixtures describing total reduced-background stresses, including unresolved-star/sky contamination. Fit total-background responses only through R16, retaining misfit. No ADU amplitude is transferred to simulated electrons. No actual ULTIMATE PSF or dust truth is inferred, and no mocks are modified/injected during this task.
